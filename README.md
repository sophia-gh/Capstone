# Tool Management System (TMS)
**version 1**
This is a repository for Tool Management System (TMS). TMS is a React-flask web app that streamlines the managment and storage a toolmaking inventory items. Below are the instructions to use TMS in a demonstration environment

## Using TMS (version 1)
1. Ensure that you are accessing the site from Kent State University or on University Wifi.
2. Navigate to the following URL in any browser:
    ``` http://capstone2.cs.kent.edu```
3. Enter the Demo Credentials in the Login Portal. 
    ``` these credentials are internal sorry :/ ```
    *if successful you will be redirected to the dashboard page*
